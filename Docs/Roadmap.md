## Етап 2: Різноманіття
**Наступна сесія починається з:** узгодити числа лучників (ціна 7 з GDD; солдати, HP, дальня й ближня шкода,
радіус, швидкість), підібрати їх від цільового часу бою, як для піхоти.

Порядок погоджено 2026-10-22:
- [ ] Пул об'єктів для солдатів (Architecture, принцип 6)
- [ ] Лучники: стоять і стріляють, поки ворог не підійде; стріляють через свою піхоту (D-014).
      Стани винести з `Squad` в окремий клас (Architecture 2.2)
- [ ] Візуал солдатів (D-015): загони не злипаються і не проходять крізь одне одного, бій «стіна на стіну»,
      гинуть передні, після бою стрій змикається вперед
- [ ] Виклик через два слоти: відлік, тап «вийти зараз», спільний кулдаун (D-007)
- [ ] Комбо: подвоєння, важкі лучники, важка піхота (`ComboBook`)
- [ ] Щитоносці й вершники (у вершників удар у момент зіткнення, GDD 3.2)
- [ ] ШІ використовує ті самі слоти і комбо
- [ ] Складність ШІ: окремі стартова їжа і швидкість їжі ворога в `BattleConfig`
- [ ] Інструмент розробника: прискорення часу ×2/×4 для плейтестів
- [ ] Рання тестова збірка на Android: дотик, safe area («чубчик»), продуктивність
- [ ] Монети з убитих солдатів
- [ ] Базові ефекти й звуки

Не беремо: автоматичний запуск тестів на GitHub (CI), рішення 2026-10-22.
